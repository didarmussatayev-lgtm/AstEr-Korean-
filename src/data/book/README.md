# Korean by book

Каждый юнит учебника — отдельный файл `uNN.ts` в этой папке, который экспортирует `BookUnit`
(см. `index.ts`) и добавляется в массив `raw`.

- **Уроки юнита** используют тот же формат, что и обычные уроки (`Lesson` в `src/lib/types.ts`):
  теория, слова, упражнения, диалог, текст. Длинный юнит можно разбить на части в `src/data/plan.ts` (ключ `bNN`).
- **Картинки** из книги кладём в `public/book/uNN/` и ссылаемся как `book/uNN/имя.jpg`:
  у слова — поле `img`, в теории — блок `{ type: 'img', src, caption }`.
- **Аудио** — тоже в `public/book/uNN/`: у слова поле `audio`, в теории блок `{ type: 'audio', src, title, transcript }`,
  в заданиях `listen` / `dictation` поле `audio` (без него звучит синтезированный голос).
- **Письмо** — упражнения `{ type: 'write', word, prompt }` (обводка и написание слогов).
- **Экзамен юнита** — массив `exam` из любых упражнений. Проходной балл 90% (`BOOK_PASS`);
  следующий юнит открывается только после сдачи экзамена предыдущего.
