# AstEr Korean 🌸

Сайт для изучения корейского с нуля. Интерфейс и объяснения: русский + английский.

Урок = **теория → слова → практика → диалог → рассказ с разбором → повторение (SRS)**.

## Запуск

```bash
npm install
npm run dev        # разработка
npm run build      # сборка в dist/
```

## Аккаунты и база

Без настройки сайт работает в локальном режиме (прогресс в браузере). Сервер скрыт за интерфейсом `Backend`
(`src/lib/backend/`), выбор по переменным окружения (см. `.env.example`):

- **Supabase** (сейчас): `VITE_SUPABASE_URL` + `VITE_SUPABASE_ANON_KEY`, таблица из `supabase/schema.sql`.
- **Свой сервер + Postgres** (планируется): `VITE_API_URL`. Контракт API, админка и схема БД — в `docs/API.md`.

Переезд на Postgres = написать сервер по `docs/API.md`, интерфейс сайта менять не нужно.

## Структура

- `src/data/hangul.ts` — буквы хангыля (звук, мнемоника, пример)
- `src/data/lessons.ts` — уроки (теория, слова, упражнения, диалог, рассказ)
- `src/lib/srs.ts` — интервальные повторения (SM-2 lite)
- `src/lib/backend/` — адаптеры сервера (supabase, rest)
- `src/lib/progress.tsx` — прогресс, серия дней, синхронизация
- `src/components/ExerciseRunner.tsx` — типы упражнений: choice, listen, build, type

Новый урок = новый объект в `lessons.ts`, код менять не нужно.

## Уроки и экзамен

Уровень 1 (12 уроков): приветствия · я — студент · числа 1 · числа 2 · это/то/вон то · глаголы -아요/어요 и 을/를 ·
места 에/에서 · дни и даты · 도/하고/안/좋아해요 · прошедшее время · желания и планы · вопросы и самопрезентация.

После всех уроков открывается **экзамен уровня** (35 вопросов, 8 форм: аудирование, выбор, пропуски, верно/неверно,
сопоставление, сборка предложения, письмо, диктант, чтение). Проходной балл 80%, пересдавать можно без ограничений.
Сдал экзамен — открывается следующий уровень (`src/lib/access.ts`). Админ сможет открыть уровень вручную (`granted`).
