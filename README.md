# AstEr Korean 🌸

Сайт для изучения корейского с нуля. Интерфейс и объяснения: русский + английский.

Урок = **теория → слова → практика → диалог → рассказ с разбором → повторение (SRS)**.

## Запуск

```bash
npm install
npm run dev        # разработка
npm run build      # сборка в dist/
```

## Сервер и база (Node + Postgres)

Папка `server/` — API на Fastify + PostgreSQL (схема `server/schema.sql` применяется при старте).
Контракт и правила доступа — `docs/API.md`.

```bash
cd server && cp .env.example .env     # DATABASE_URL, JWT_SECRET, ADMIN_EMAIL, ADMIN_PASSWORD
npm install
npm run dev                            # http://localhost:3000, первый админ создаётся из ADMIN_EMAIL
npm test                               # e2e-тесты на настоящем Postgres (нужна БД aster_test)
```

Сайт ученика подключается к серверу переменной `VITE_API_URL` (в корне `.env`): адрес API, либо `/` если сайт
и админка раздаются самим сервером. Без неё сайт работает локально (прогресс в браузере); можно и Supabase
(`.env.example`).

## Админка (React)

Папка `admin/`: список и поиск учеников, прогресс (уроки, экзамены, XP, серия), **ручное открытие уровней**,
**новый пароль без почты и ссылок** (админ вводит пароль и сообщает его ученику; старые сессии ученика
завершаются), сброс экзамена/прогресса, роли, создание и удаление учётных записей, журнал действий.

```bash
cd admin && cp .env.example .env && npm install && npm run dev    # http://localhost:5174
```

### Один сервер на всё (продакшн)

```bash
VITE_API_URL=/ npm run build            # сайт -> dist/
(cd admin && npm run build)             # админка -> admin/dist/
(cd server && npm run build && NODE_ENV=production npm start)   # сайт на /, админка на /admin/
```

В продакшне обязателен длинный `JWT_SECRET`; за прокси включите HTTPS.

### Railway (Dockerfile)

В корне есть `Dockerfile` и `railway.json`: один сервис отдаёт сайт (`/`), админку (`/admin/`) и API.

1. Создайте сервис из этого репозитория и добавьте Postgres.
2. В **Variables** сервиса задайте (в репозиторий пароли не кладём):

| Переменная | Значение |
|---|---|
| `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` |
| `JWT_SECRET` | длинная случайная строка (`openssl rand -hex 32`) |
| `ADMIN_EMAIL` | логин первого админа, например `admin` (можно и e-mail) |
| `ADMIN_PASSWORD` | пароль админа, не короче 6 символов; задайте свой, не `admin` |

3. Деплой. При старте создаются таблицы и первый админ (только если такого логина ещё нет).
4. Зайдите на `/admin/` под этим логином и создавайте учётные записи; учеников можно и не регистрировать вручную:
   `ALLOW_REGISTRATION=false` закрывает саморегистрацию.

Админ может создавать учётные записи с простым логином без `@`; ученики регистрируются на сайте по e-mail.

## Структура

- `src/data/hangul.ts` — буквы хангыля (звук, мнемоника, пример)
- `src/data/lessons.ts` — уроки (теория, слова, упражнения, диалог, рассказ)
- `src/data/plan.ts` — порядок подачи урока по шагам (какие слова, правила и упражнения и когда)
- `src/data/mnemonics.ts` — запоминалки к словам (картинка из эмодзи + история по созвучию)
- `src/lib/steps.ts`, `src/lib/quiz.ts` — сборка урока из мелких шагов и автогенерация мини-проверок
- `src/lib/srs.ts` — интервальные повторения (SM-2 lite)
- `src/lib/backend/` — адаптеры сервера (rest, supabase)
- `server/` — API (Fastify + Postgres), `admin/` — админка (React)
- `src/lib/progress.tsx` — прогресс, серия дней, синхронизация
- `src/components/ExerciseRunner.tsx` — типы упражнений: choice, listen, build, type

Новый урок = новый объект в `lessons.ts`, код менять не нужно.

## Уроки и экзамен (уровень 1 = A1)

24 урока: приветствия · я — студент · числа 1 · числа 2 · это/то/вон то · глаголы -아요/어요 и 을/를 · места 에/에서 ·
дни и даты · 도/하고/안/좋아해요 · прошедшее время · желания и планы · вопросы и самопрезентация · прилагательные ·
семья · заказ в кафе · распорядок дня · транспорт · погода (ㅂ-глаголы) · здоровье · просьбы (-(으)세요, -아/어 주세요) ·
умения (-ㄹ 수 있어요, 못) · хобби и частота (ㄷ-глаголы) · связки (-고, -지만, -아서/어서) · живые фразы и этикет.
Плюс хангыль (24 буквы). Около 300 слов и фраз в карточках повторения.

В конце **экзамен уровня** (62 вопроса, 8 форм: аудирование, выбор, пропуски, верно/неверно, сопоставление, сборка
предложения, письмо, диктант, два текста для чтения). Проходной балл 80% (50 из 62), пересдавать можно без ограничений.
Сдал экзамен — открывается следующий уровень (`src/lib/access.ts`); админ может открыть уровень вручную.

### Как построен урок (мелкими шагами)

Урок — это цепочка шагов, а не одна большая простыня:
**вспомним прошлый урок** → **2–4 новых слова** (карточка с картинкой и запоминалкой) → **мини-проверка именно этих слов** →
ещё слова → **смешанное повторение всего выученного** → **одно правило** → **упражнения именно на него** → … →
диалог → рассказ → итоговое повторение → готово. Мини-проверки (картинка, значение, обратный перевод, аудио, сопоставление)
генерируются автоматически и каждый раз новые. Если ответить неверно, под ответом показывается запоминалка этого слова;
она же видна на обороте карточки в «Повторении».

Новый урок: опишите `vocab`, `theory`, `exercises` как раньше, добавьте запоминалки в `mnemonics.ts` и порядок в `plan.ts`
(без плана урок собирается по умолчанию: слова по три, правила по порядку).

### Письмо рукой (пошагово)

Упражнение `write` (`{ type: 'write', word: '네', prompt, tr }`) ведёт от простого к сложному: **собрать слог из букв в «кубике»**
(перетащить или нажать букву и клетку) → **обвести пальцем** → **написать слог** (в кубике подсказаны буквы) → **два слога** →
**всё слово** (кубики пустые). Вертикальные гласные стоят справа от согласной, горизонтальные — под ней, патчим — внизу.
Форма проверяется по центральной линии буквы (`src/lib/drawScore.ts`), проверка мягкая; всегда можно нажать «Я справился».
Обводить отдельные буквы можно на странице «Хангыль». Письмо есть во всех 24 уроках (по 1–3 слова на урок, 44 упражнения,
слова из 1–3 слогов); в экзамене пока набор с клавиатуры.

Прогресс внутри урока (шаг, раздел теории, номер упражнения) запоминается и синхронизируется: можно выйти и вернуться.
