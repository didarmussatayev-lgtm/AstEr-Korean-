# AstEr Korean 🌸

Сайт для изучения корейского с нуля. Интерфейс и объяснения: русский + английский.

Урок = **теория → слова → практика → диалог → рассказ с разбором → повторение (SRS)**.

## Запуск

```bash
npm install
npm run dev        # разработка
npm run build      # сборка в dist/
```

## Аккаунты и база (Supabase)

Без настройки сайт работает в локальном режиме (прогресс в браузере).

1. Создай проект на supabase.com и выполни `supabase/schema.sql` в SQL-редакторе.
2. Скопируй `.env.example` в `.env` и впиши `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
3. После входа прогресс синхронизируется между устройствами (побеждает более новая копия).

## Структура

- `src/data/hangul.ts` — буквы хангыля (звук, мнемоника, пример)
- `src/data/lessons.ts` — уроки (теория, слова, упражнения, диалог, рассказ)
- `src/lib/srs.ts` — интервальные повторения (SM-2 lite)
- `src/lib/progress.tsx` — прогресс, серия дней, синхронизация
- `src/components/ExerciseRunner.tsx` — типы упражнений: choice, listen, build, type

Новый урок = новый объект в `lessons.ts`, код менять не нужно.
